# أرخص: قارن الأسعار في الخليج

تطبيق ويب يبحث عن أي منتج في متاجر الإمارات والسعودية والكويت وقطر والبحرين وعُمان، ويرتب العروض حسب **السعر النهائي اللي يوصلك فيه المنتج** بعد التوصيل. يشتغل على الجوال والكمبيوتر، ويتثبّت على شاشة الجوال كتطبيق (PWA).

## التشغيل على جهازك

تحتاج [Node.js](https://nodejs.org) الإصدار 22.13 أو أحدث.

```bash
npm install
cp .env.example .env      # بعدين حط مفاتيحك في .env
npm start                 # افتح http://localhost:3000
```

بدون أي مفاتيح، التطبيق يشتغل **بوضع تجريبي** بأسعار غير حقيقية، ويطلع شريط أصفر فوق يوضح هذا.

## تفعيل الأسعار الحقيقية

### 1. خدمة البحث المجمّعة (ابدأ بهذي)
1. سجّل في [SerpApi](https://serpapi.com) وانسخ الـ API Key.
2. حطه في `.env`:  `SERPAPI_KEY=...`
3. أعد تشغيل الخادم.

كل بحث داخل بلد واحد = طلب واحد من رصيد SerpApi. بحث «الخليج كله» = 6 طلبات. النتائج تنحفظ 30 دقيقة (`CACHE_MINUTES`)، فالبحث المتكرر عن نفس المنتج ما يصرف رصيد.

### 2. أمازون الرسمي (Creators API)
أمازون أوقفت واجهة PA-API 5 في 2026 وصار البديل **Creators API**.
1. سجّل في Amazon Associates للإمارات و/أو السعودية.
2. من لوحة Associates افتح Creators API وأنشئ بيانات الدخول (يتطلب عادةً مبيعات مؤهلة خلال آخر 30 يوم).
3. عبّي `AMAZON_CLIENT_ID` و`AMAZON_CLIENT_SECRET` و`AMAZON_PARTNER_TAG_AE` / `AMAZON_PARTNER_TAG_SA`.

روابط أمازون تحمل الـ Partner Tag حقك، فتاخذ عمولة على كل عملية شراء من التطبيق.

> مسار البحث مضبوط على `/catalog/v1/searchItems`. إذا غيّرته أمازون، عدّله في `AMAZON_SEARCH_PATH` بدون ما تلمس الكود.

### 3. سحب البيانات من مواقع المتاجر
للمتاجر اللي ما تطلع في المصدرين الأولين. كلها مقفلة افتراضياً في `config/scrapers.json`.
1. تأكد إن شروط استخدام المتجر تسمح بالقراءة الآلية.
2. أضف المتجر مع رابط البحث ومحددات CSS (الملف فيه مثال).
3. جرّبه: `node server/sources/scraper.js <id> "iphone 17 pro"`
4. غيّر `enabled` إلى `true`.

الخادم يحترم ملف `robots.txt` لكل موقع تلقائياً.

## كيف يشتغل البحث

```
بحث المستخدم
  ↓ نحوّل الكلمات العربية لمرادفها الإنجليزي (آيفون → iphone، جيجا → gb)
  ↓ نسأل المصادر الثلاثة بالتوازي، لكل دولة في النطاق
  ↓ نطابق المنتج: نستبعد الإكسسوارات، المستعمل، السعة أو النسخة المختلفة (Pro ≠ Pro Max)
  ↓ نحوّل للدرهم، نتعرف على المتجر، نضيف التوصيل لبلد المستخدم
  ↓ نستبعد الأسعار الشاذة والمكررة (عرض واحد لكل متجر)
  ↓ نرتب حسب السعر النهائي، ونسجّل أرخص سعر اليوم في تاريخ الأسعار
```

| الملف | وش يسوي |
|---|---|
| `server/core/normalize.js` | توحيد النص العربي والإنجليزي والأرقام والوحدات |
| `server/core/match.js` | قرار «هل هذا نفس المنتج؟» |
| `server/core/engine.js` | خط البحث كامل |
| `server/core/stores.js` + `config/stores.json` | أسماء المتاجر بالعربي وقواعد التوصيل |
| `server/sources/*.js` | مصدر لكل ملف: SerpApi، أمازون، السحب، والتجريبي |
| `server/alerts.js` | فحص تنبيهات الأسعار كل كم ساعة |
| `public/` | الواجهة |

## أشياء لازم تعرفها

- **التوصيل بين الدول:** افتراضياً العروض من دولة ثانية تطلع تحت «في دول ثانية» وما تنحسب كأرخص سعر، لأن أغلب المتاجر ما تشحن بين دول الخليج. إذا تأكدت إن متجر يشحن لدولة ثانية، أضفها في `crossBorder` داخل `config/stores.json`، وبعدها يدخل عرضه في المقارنة.
- **رسوم التوصيل** في `stores.json` تقديرية وتطلع في التطبيق بكلمة «تقديري». إذا أرجعت SerpApi رسوم التوصيل الفعلية، نستخدمها بدل التقدير.
- **تاريخ السعر** يتكوّن من عمليات البحث نفسها: أول ما أحد يبحث عن منتج نسجّل أرخص سعر له في ذاك اليوم.
- **التنبيهات** تنفحص كل `ALERT_CHECK_HOURS` ساعات. لإرسالها واتساب أو تيليجرام أو إيميل، حط رابط Webhook من Make أو Zapier أو n8n في `ALERT_WEBHOOK_URL`.
- **الباركود** يشتغل بالكاميرا على Chrome في أندرويد. في المتصفحات اللي ما تدعمه، المستخدم يكتب الرقم.

## النشر على الإنترنت

أي خدمة تشغّل Node أو Docker تنفع. الأسهل [Render](https://render.com) أو [Railway](https://railway.app):
1. ارفع المشروع على GitHub.
2. أنشئ Web Service جديدة من المستودع (Build: `npm install`، Start: `npm start`).
3. أضف متغيرات `.env` في إعدادات الخدمة.
4. أضف قرص دائم (Persistent Disk) وحط مساره في `DB_PATH`، مثلاً `/data/arkhas.db`، عشان ما يضيع تاريخ الأسعار والتنبيهات مع كل نشر.

أو بـ Docker:
```bash
docker build -t arkhas .
docker run -p 3000:3000 --env-file .env -v arkhas-data:/data arkhas
```
